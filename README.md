# Первый шаг: персональный помощник на GigaChat

Сервер-посредник нужен, потому что ключ GigaChat нельзя класть прямо в страницу: его увидел бы любой. Сервер хранит ключ у себя, сам получает токен доступа (он живёт 30 минут), ставит запросы в очередь (бесплатный режим обрабатывает один запрос за раз) и отдаёт страницу бота.

## Запуск (Windows)

1. **Установи Node.js 18+** с nodejs.org (кнопка LTS).
2. **Скачай проект** (Code → Download ZIP) и распакуй.
3. **Ключ GigaChat (по желанию).** Скопируй `.env.example` в `.env` и вставь свой ключ авторизации: developers.sber.ru → проект GigaChat API (бесплатный тариф для физлиц) → «Ключ авторизации».
   Без ключа помощник тоже запустится, но в **упрощённом режиме**: ситуации и подсказки из встроенной базы, без живого диалога.
4. **Запусти** двойным щелчком `start.bat` (или `node server.js` в папке проекта) и открой http://localhost:3000.
   Вверху справа будет написано «GigaChat», если ключ подключён, или «Упрощённый режим».

Сертификат Минцифры сервер скачает сам в папку `certs` и будет использовать **только для своих запросов к GigaChat**: в систему ничего не устанавливается.

Быстрый просмотр без установки: открой `public/index.html` в браузере (работает упрощённый режим).

Микрофон работает на localhost в Chrome, Edge и Яндекс Браузере.

## Безопасность
- Файл `.env` с ключом указан в `.gitignore` и в репозиторий не попадает. Никогда не загружай его на GitHub.
- Ключ хранится только на сервере, браузер его не видит.
- Сервер ограничивает частоту запросов (20 в минуту с одного адреса) и размер сообщений.

## Если что-то не работает
| Сообщение | Что делать |
|---|---|
| «Не найден сертификат НУЦ Минцифры» | Сервер не смог скачать сертификат: сделай по шагам из `certs/README.txt` (только скачать файл, не устанавливать) |
| «GigaChat отклонил ключ авторизации» | Проверь ключ в `.env`: нужен ключ авторизации (длинная строка, оканчивается на `==`), без слова Basic |
| «GigaChat занят» | Бесплатный режим обрабатывает один запрос за раз, подожди немного |
| Вверху написано «Офлайн-режим» | Сервер не видит ключ: открой http://localhost:3000/api/health, там должно быть `"keySet":true` |

## Как получить ссылку для жюри
- **Проще всего:** запустить локально и записать видео (условия кейса это разрешают).
- **Публичная ссылка:** любой хостинг с Node.js, например облачные приложения российских провайдеров или Render. Загрузи проект, задай переменную окружения `GIGACHAT_AUTH_KEY` в панели хостинга (файл `.env` не загружай) и команду запуска `node server.js`.

## Структура
```
server.js        сервер-посредник (без внешних библиотек)
public/index.html  страница бота
certs/           сюда сервер сам кладёт сертификат Минцифры
start.bat        запуск двойным щелчком (Windows)
.env.example     образец настроек (скопируй в .env и вставь ключ)
ARCHITECTURE.md  архитектура и стек для сдачи
```
