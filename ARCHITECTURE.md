# Первый шаг — персональный помощник для абитуриента и стажёра

Кейс «Софтлайн Решения»: Цифровое наставничество и AI-менторство.

## Как запустить
- **Демо на claude.ai (артефакт):** открывается по ссылке, подключение к модели происходит автоматически.
- **Свой сайт / компьютер:** `node server.js` из архива — бот работает через GigaChat, ключ хранится на сервере. Голосовой ввод и PDF работают здесь.
- **Упрощённый режим:** если подключения нет, бот работает по встроенному банку ситуаций и базе знаний.

## Стек
- Один HTML-файл: HTML, CSS и чистый JavaScript, без фреймворков.
- Языковая модель: GigaChat через сервер-посредник `server.js` (в демо на claude.ai — встроенная модель платформы); при отсутствии связи — упрощённый режим на правилах.
- Сервер-посредник: Node.js 18+ без внешних библиотек. Хранит ключ, обновляет OAuth-токен, ставит запросы в очередь, ограничивает частоту запросов.
- Голос: Web Speech API (`ru-RU`). Запись идёт, пока пользователь не нажмёт «стоп»: паузы и запинки не обрывают её, распознавание перезапускается и текст склеивается. Ответы можно озвучивать.
- Память: `localStorage` браузера. Хранятся слабые и сильные стороны, ситуация пользователя и сами диалоги (отдельно для каждого режима и сценария), поэтому после переключения или перезагрузки разговор продолжается с того же места.
- Экспорт: заметка .txt (через возможность `downloads` в артефакте или обычное скачивание), PDF через печать браузера.

## Режимы
- **Тренажёр:** знакомство → 4 жизненные ситуации с каверзными вопросами → разбор «Это верно / Что можно улучшить / Удачный пример ответа» → итог → свободные вопросы.
- **Справка:** ответы на вопросы по базе знаний с источниками.

## База знаний
21 статья по трём сценариям, из них 6 — реальные случаи из СМИ и исследований (hh.ru, Superjob, Газета.Ru, юридические разборы, новости приёма 2026). 15 кейсов для тренажёра, 13 типовых ошибок. У каждой статьи указаны источники.

## Архитектура
```
Голос/текст ─► Диалог-менеджер (этапы: знакомство → практика → итог → вопросы)
                  │
                  ├─► Сборщик промпта: роль персонального помощника + правила общения
                  │      + база знаний (15 статей с id) + банк кейсов сценария
                  │      + типовые ошибки + слабые зоны из памяти + этап/счётчик
                  │
                  ├─► Подключение: GigaChat (сервер) | встроенная модель демо | упрощённый режим (запасной вариант)
                  │
                  └─► Ответ модели в JSON: reply, stage, case_done, feedback{good, improve, example},
                       sources[id], weak[], strong[], mistakes[], situation, quick[]
                          │
                          ├─► UI: сообщение, карточка разбора, источники, подсказки-кнопки
                          └─► Память: слабые/сильные зоны, ошибки, ситуация → следующая сессия
```

Почему так устроено:
- Модель берёт факты только из базы знаний и возвращает id статей. Источники под ответом подставляет код, а не модель, поэтому выдуманных ссылок не бывает.
- Ответ в формате JSON позволяет коду вести этапы, считать разобранные ситуации и обновлять память о слабых местах (этап 4).
- Если модель недоступна, бот автоматически переходит в упрощённый режим.

## Этика
Используются только открытые источники с указанием ссылок. Личные данные бот не запрашивает. Предупреждение о том, что советы носят информационный характер, показано в интерфейсе.
